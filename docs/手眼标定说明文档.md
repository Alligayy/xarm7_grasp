### xArm7 + D455 眼在手标定说明文档

你可以将以下内容保存为 `README_Calibration.md`，方便以后随时查阅。

#### 1. 软硬件基础环境

* **当前操作系统与 ROS 版本**：Ubuntu 22.04 + ROS2 Humble
* **硬件配置**：xArm7 机械臂 + RealSense D455 深度相机（眼在手 Eye-in-Hand 安装）
* **核心软件包**：`easy_handeye2`（源码编译）、`aruco_ros`
* **标定板要求**：Original ArUco 字典，ID 55，边长 100mm。**注意**：务必实际测量一下打印的ArUco码的尺寸，打印时须选择按照实际大小进行打印，否则尺寸可能对不上。


#### 2. 标定执行步骤

1. **启动系统**：一键启动运行 `ros2 launch xarm7_grasp calibration_all.launch.xml`。
        该launch文件包含：
            启动机械臂和相机`xarm7_grasp`、
            启动ArUco码识别`aruco_ros`、
            启动手眼标定程序`easy_handeye2` 

     **手动启动**`aruco_ros`和`easy_handeye2`：
        *1*. 先手动启动真实机械臂和相机，并确保相机能清晰稳定地看到二维码。此处可以直接调用`xarm7_grasp`包下的`xarm7_grasp_all.launch.xml`，但注意修改相机参数，将`点云`和`深度对齐`设为false。
        *2*. 启动ArUco码识别`aruco_ros`：（*新开终端运行*）
            ros2 run aruco_ros single --ros-args \
            -p marker_id:=55 \
            -p marker_size:=0.1 \
            -p marker_frame:=camera_marker \
            -p reference_frame:=camera_color_optical_frame \
            -p camera_frame:=camera_color_optical_frame \
            -p image_is_rectified:=true \
            -r /image:=/camera/camera/color/image_raw \
            -r /camera_info:=/camera/camera/color/camera_info
        *3*. 启动手眼标定程序`easy_handeye2`：（*新开终端运行，启动之前可以先开视觉监控*）
            ros2 launch easy_handeye2 calibrate.launch.py \
            name:=xarm7_d455_calibration \
            calibration_type:=eye_in_hand \
            tracking_base_frame:=camera_color_optical_frame \
            tracking_marker_frame:=camera_marker \
            robot_base_frame:=link_base \
            robot_effector_frame:=link_eef

2. **视觉监控**：启动`easy_handeye2`之前可以新开终端运行 `ros2 run rqt_image_view rqt_image_view`，订阅 `/aruco_single/result`，确认画面中ArUco码中心稳定出现三色坐标轴。说明系统已成功识别到ArUco码，否则直接运行`easy_handeye2`会报错。

3. **数据采集**：
* 在弹出的 `easy_handeye2` GUI 界面中点击 `Take Sample` 进行采点。
* 使用示教器或 RViz2 移动机械臂改变相机姿态，**必须保证相机能清晰稳定地看到二维码**。
* **采样要求**：采集 15~20 个点。姿态变化要丰富，在 X、Y、Z 轴平移的同时，务必包含 Roll、Pitch、Yaw 的倾斜和旋转。

4. **解算与保存**：
* 在 GUI 界面切换算法进行解算（系统会自动后台计算）。
* 确认结果后点击 `Save`。文件将以 `.calib` 格式静默保存在隐藏目录 `/home/gao/.ros2/easy_handeye2/calibrations/xarm7_d455_calibration.calib` 下。在`gao`文件夹下点击 `Ctrl+H`显示隐藏文件。


#### 3. 算法选择与误差验证

* **首选算法**：`OpenCV/Daniilidis`。该算法使用双四元数模型同步求解旋转和平移，抗噪性强，精度最高。备选为 `Tsai-Lenz` 或 `Park`。
* **物理校验（盲测）**：观察终端输出的 $4 \times 4$ 齐次变换矩阵的第四列（平移向量 $X, Y, Z$）。用卷尺实测 D455 相机中心到机械臂末端法兰盘 (`link_eef`) 的物理距离，两者若基本吻合（误差在毫米级），则标定矩阵有效。
* **RViz2 最终校验**：标定完成后，在抓取启动文件中开启点云 (`align_depth.enable:=true`)。让机械臂末端触碰桌面特征点，观察 RViz2 中机械臂模型末端与真实点云是否严丝合缝。


#### 4. 关键注意事项 (Troubleshooting)

* **深度对齐参数**：标定期间，务必将 `align_depth.enable` 保持为 `false`。标定仅依赖 RGB 图像（PnP 算法），关闭深度对齐可节省算力和带宽、消除延迟，确保采样瞬间的画面绝对清晰，避免相机发热严重。抓取阶段再将其开启。


* **无报错即胜利**：由于新版 GUI 精简了误差显示，终端不输出具体 RMS 数值。核心判断标准是**物理校验**和**点云重合度**。
